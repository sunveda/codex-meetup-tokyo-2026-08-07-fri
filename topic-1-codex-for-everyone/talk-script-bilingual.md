# Codex for Everyone — 5-minute LT script

## 0:00–0:20 — Audience topic

**English:** I need one topic from the audience—anything: food, travel, education, or a local problem.

**日本語:** みなさんからテーマをひとつください。食べ物、旅行、教育、地域の課題、何でも大丈夫です。

## 0:20–0:45 — One command

**English:** I will give Codex one plain-language command. No code. Then it works while I show five people who can use it.

**日本語:** 自然な言葉で、指示はひとつだけです。コードは書きません。Codexが作っている間に、5人の使い方を紹介します。

**Live prompt:**

> Build a bilingual one-page website about **[AUDIENCE TOPIC]**. Make it friendly, visual, and mobile-ready. Run it locally and open the result.

> **［会場のテーマ］**について、親しみやすくビジュアルで、スマホ対応のバイリンガル1ページサイトを作って。ローカルで実行して、結果を開いて。

## 0:45–3:20 — Five people, two outcomes each

1. **Owner / 店主** — Menu + site / メニュー＋サイト
2. **Teacher / 先生** — Lesson + quiz / 授業＋クイズ
3. **Analyst / 分析する人** — Sheet + decision / 表＋判断
4. **Creator / クリエイター** — Visual + plan / ビジュアル＋発信計画
5. **Organizer / 主催者** — Event + community / イベント＋仲間

Keep each example to about 30 seconds: name the person, show the two outputs, and move on.

## 3:20–4:05 — Reveal

**English:** Now let us return to Codex and see what one idea plus one command created. If it needs a change, give me one improvement.

**日本語:** ではCodexに戻りましょう。アイデアひとつ、指示ひとつで、何ができたか見てみます。改善点があれば、ひとつ教えてください。

## 4:05–5:00 — Introduction and invitation

**English:** I am Sarveshwar Singh from Sunveda. I am building a community where people learn and teach AI together—especially people who do not call themselves technical. Scan the website or join our LINE community. Thank you.

**日本語:** SunvedaのSarveshwar Singhです。技術者でない人も含め、みんなでAIを学び、教え合うコミュニティを作っています。ウェブサイト、またはLINEコミュニティから参加してください。ありがとうございました。

## Live-demo safety

- Open Codex and the browser before going on stage.
- Paste the prompt into a ready task; only replace **[AUDIENCE TOPIC]**.
- Keep a completed example open in another tab as a fallback.
- At 3:20, reveal whatever is ready. Do not wait for perfection.
