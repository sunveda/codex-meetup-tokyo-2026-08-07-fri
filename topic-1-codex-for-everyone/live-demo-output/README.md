# Live Demo: Japan Travel Website

Built live with Codex at **Codex Meetup Tokyo #2 — August 7, 2026** from an audience request for a Japan tourist-agent website aimed at European travellers.

## Live website

**[Open Kokoro Japan Journeys](https://kokoro-japan-journeys.sarveshwar1986.chatgpt.site)**

## What Codex created

- A visual guide to 20 beautiful places across Japan
- 27 European language choices with browser-language detection
- Destination search and travel-style filters
- Responsive mobile and desktop layouts
- A trip-planning enquiry experience
- A social-sharing image and source attribution for destination photography

The complete ChatGPT Sites source is stored in [`japan-travel-site/`](./japan-travel-site/).
