# このLTはCodexと一緒に作りました

**Codex Meetup Tokyo #2 - 2026年8月7日（金）**

## サブタイトル

非エンジニアがイベントの発見から登壇準備まで進めた実例

## 概要

このLTでは、Codex Meetup Tokyo #2を知ってから、この発表を準備するまでの実際のプロセスを紹介します。

最初に、日本語で書かれたイベントページをCodexに共有しました。ページを直接確認できなかったためPDFを渡すと、Codexはイベントの内容を理解し、英語で分かりやすく説明しました。さらに、LT登壇者の募集を見つけ、案内を翻訳し、発表テーマを一緒に考え、応募文と発表内容の準備までサポートしました。

この実体験を通して、技術的な知識がない人でも、Codexを使って言語や情報の壁を越え、分からない状態から具体的な行動と完成した成果につなげられることを紹介します。

## ストーリーの流れ

1. 日本語のイベントページを共有する
2. イベントのPDFをCodexに理解してもらう
3. イベント内容とLT募集を英語で確認する
4. 発表テーマと応募文をCodexと一緒に作る
5. LTの構成と資料を完成させる
6. 「今見ているこのLT自体がCodexとの成果物」であることを示す

## 参加者に持ち帰ってほしいこと

Codexは質問に答えるだけのツールではありません。目的を理解し、障害に対応しながら、興味を具体的な行動と成果に変えるための仕事のパートナーとして使えます。
